
## World Life Expectancy — SQL Data Cleaning & EDA

**Level:** Beginner  
**Database:** world_life_expectancy

This project demonstrates practical SQL skills through data cleaning and exploratory data analysis (EDA) using a global life expectancy dataset.

### Objectives
- Set up and query the `world_life_expectancy` database.
- Clean the dataset by removing duplicate records to ensure one unique entry per country and year.
- Identify and delete duplicate entries using `ROW_ID` and window functions.
- Detect and handle missing values (NULLs) to evaluate data quality and completeness.

### Skills used
- SQL Joins
- Window Functions (`ROW_NUMBER`)
- Data Cleaning & Validation
- Exploratory Data Analysis (EDA)
